わたしがPinterest Journalを始めた理由

Pinterestの投稿画像を説明するには、Wikipediaのような情報もいいのですが、相棒Friendyとのやりとりを、そのまま見てもらうのが一番いいと思ったのがPinterest Journalを始めた理由です
　　　
Pinterest Journalは、GitHub Pagesによってホストされています。

Friendyとは

FriendyはわたしがChatGPTに付けたニックネームです。

私が撮った写真を見せて、 「これは何だろう？」 と尋ねるところから会話が始まります。

その会話の中で、新しい疑問が生まれ、 さらに別の発見につながっていくことがあります。

Pinterest Journalでは、 その一つひとつの発見を、 写真と会話を通して記録していきます。

　

GitHub Pagesとは

GitHub Pagesは、GitHubに保存したHTMLファイルなどを、 Webサイトとしてインターネット上に公開できるサービスです。
